## 开始前

- [ ] 写下本次想解决的具体问题

- [ ] 在日历里留出一段专注时间

## 学习时

- [ ] 只保留与当前任务相关的资料
- [ ] 用自己的话记下三个要点
- [ ] 完成一个例子或一次实际操作
- [ ] 记下一个还没有弄懂的问题

## 学习后

- [ ] 保存自己的输出，而不只是资料链接
- [ ] 回答：我现在能做什么了？
- [ ] 选择下一步行动，写下时间

## 每周回顾

- [ ] 检查收藏是否仍然有用
- [ ] 归档已完成的内容
- [ ] 移除不再需要的收藏
- [ ] 回答一个上周留下的问题
